# 手机体验与验证边界

## 可交付的变化

| 项目 | 精细 | 流畅 |
| --- | --- | --- |
| GLB 文件 | 7,661,316 字节 | 3,447,116 字节（减少 55.0%） |
| 三角形 | 1,170,704 | 483,883（减少 58.7%） |
| 显示树木 | 10,983 | 2,746 |
| 建筑、道路、水面、地标 | 保留 | 全部保留 |
| 地形网格 | 390 × 294 | 两个方向各降低一半采样密度 |
| 阴影 | 实时阴影，未变化时复用 | 关闭 |
| 静止场景 | 保留水面动效 | 停止重复绘制 |
| 动画目标上限 | 跟随刷新时机 | 30 fps 上限，并非性能保证 |

地形、建筑、植被和道路按约 8 km 空间网格分组，Three.js 可剔除视野外的组。当前是一次下载所选模型，尚未进行按城区网络流式加载。所有地标在两种模型中保留相同造型。

自动模式在窄屏、低高度横屏、主要输入为触屏或启用节省流量偏好时选择轻量模型。在持续前台动画不足 25 fps 时逐步降低像素比例，最低 0.85；静止和后台状态不用于降档判断。手动选择精细时不会自动降低画质。

手机菜单使用有焦点约束与关闭后焦点恢复的抽屉。主要控制至少 44 px，支持安全区域边距。地标说明默认收起，避免挡住近景。双指手势、取消手势、拖动后返回起点均不作为地标点击。

## 已完成的检查

模型检查程序对两种 GLB 逐个比较建筑、道路、水面与地标的三角形数量，防止轻量化遗漏城市要素。点触单元检查包含小范围手指抖动、双指释放顺序、返回原点的拖动、取消事件、次要鼠标按钮及 DOM 事件原型字段。

浏览器尺寸和交互的最终检查记录见 `VALIDATION.md`。

## 真机如何测

在手机打开公开站点并加 `?stats=1`，可看到所选模型、模型大小、场景初始化耗时、当前绘制帧率、三角形与绘制调用数、像素比例。“静止省电”表示没有重复绘制，不能解读为掉帧。

初始化耗时受缓存、网络与解码影响；一次读数不是冷启动基准。三角形和调用数是当前渲染统计，精细模式的阴影更新可能增加它们。

记录设备型号、系统和浏览器版本，分别测试无缓存首次打开、连续拖动 30 秒、切换地标、横竖屏及使用 10 分钟后的发热。将流畅与精细模式在同一设备和网络下比较。当前没有取得实机数据，不宣称特定手机帧率、温升或弱网加载成绩。
