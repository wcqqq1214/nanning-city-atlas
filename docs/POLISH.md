# 下一步打磨建议

本次已扩充到 15 个探索点，修复小地图图标尺寸，降低日间过强的曝光，按地标配置镜头距离，并使长标签按实际宽度避让。

下面是后续建议，尚未作为新功能实现。

| 优先级 | 方向 | 具体收益与边界 |
| --- | --- | --- |
| 高 | 把地标近景做扎实 | 优先打磨会展中心花瓣、南宁大桥拱肋、艺术中心云棚，再补桥墩、台阶和滨江步道。保持整体低面数风格，让走近时仍能辨认建筑，而不是给全部街区堆细节。 |
| 高 | 按主题组织游览 | 15 个点已有完整漫游，但单一路线较长。可提供“老城记忆”“邕江山水”“现代南宁”三条短路线，配少量有来源的历史与空间故事。 |
| 高 | 先测手机，再做性能优化 | 在真实手机测首次加载、拖动帧率与发热，再决定是否按城区拆分模型、分级加载、降低阴影分辨率。当前未取得真机性能数据，不预先宣称性能瓶颈。 |
| 中 | 丰富场地层次 | 继续调整城区、山林、岸线的明暗与主次，补重要滨水空间；目前很多道路是贴地带状面，近景细节有限。 |
| 中 | 提升分享和导出 | 支持带地名与图例的图片，以及保存当前视角和环境的链接。当前导出只包含 WebGL 画面，菜单与 HTML 地名不在图片中。 |

建议下一轮先做“地标近景 + 三条主题路线”，能在不扩大地理范围的情况下明显提升可逛性。五象湖、广西体育中心、园博园等外围地点应另开扩区任务，先补齐对应的高程和水系数据再添加模型。
