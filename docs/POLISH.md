# 后续打磨建议

本轮已完成城西扩区、20 个探索点、三处重点地标近景、手机轻量模型、自动画质、菜单抽屉与近景卡片调整。

后续建议（尚未实现）：

- 在真实 iPhone 与 Android 设备记录首次加载、连续拖动帧率、内存和十分钟温升。当前已有可选 `?stats=1` 诊断入口，但桌面尺寸模拟不替代真机。
- 将 20 站长漫游拆成“老城记忆”“邕江山水”“现代南宁”主题短路线，配有来源的简短故事。
- 细化其他地标的屋面与入口，以及重要滨江步道；继续保持低面数风格。
- 提升图片导出和分享：可选地名与图例，以及保存当前镜头、环境的链接。
- 外围继续扩区时先补齐高程与水系；当前包含部分五象新区，但尚非全市行政范围。独立精细地标仍需逐个建模。
