# 验证记录

环境：macOS Apple Silicon，Node.js 26.8.1，Blender 5.2.1 LTS。验证日期：2026-09-08。

## 已执行

- TypeScript 严格类型检查。
- authored code 的 Oxlint 检查。预装 UI 组件、随组件附带的移动端 hook 和第三方 Draco 解码器保持上游源码，不纳入项目代码 lint。
- npm 依赖安全审计；修复了初始模板中的已知依赖问题。
- 生产构建与本地 HTTP 路由/模型响应检查。
- GitHub Pages 子目录静态导出通过；本地 HTTP 检查首页以及 21 个脚本、样式、模型、元数据、图标、RSC 与解码器资源，确认响应成功，WASM MIME 类型正确。
- 根目录静态导出通过；原有 Cloudflare Workers 生产构建继续通过。构建脚本会检查首页资源前缀及对应文件，防止 Pages 项目子目录下的资源路径遗漏。
- Blender 后台生成 `.blend` 和 Draco 压缩 GLB。
- 浏览器实际解码并载入更新后的 Draco GLB；模型包含 7 个基础图层对象与 14 个独立地标对象。
- Blender 场景离线渲染，检查河道形态、丘陵、植被、建筑和场景范围。
- `scripts/validate_assets.py` 检查高程网格、坐标范围、水面三角形覆盖率、补充建筑避让水面/公园、15 个地标的目录一致性与坐标投影、GLB 结构和大小预算。
- Chrome 桌面视口实际检查首页、8 个新增地标的选择与详情、文化艺术中心近景、日夜切换、15 站漫游计数、末站到首站的自动循环与暂停。
- 390 × 844 窄屏检查城市菜单打开、滚动到末站、选择后收起和地标定位；关闭菜单后，侧栏不再出现在可访问性树中。
- 桌面与窄屏检查小地图图标和河湖内容；按标签真实宽度避让，视口变化时重新测量。

## 验证边界

浏览器检查使用桌面 Chrome 与视口尺寸模拟，不等于移动端实机测试。未执行手机 GPU 帧率、发热或弱网加载测量，也未覆盖所有浏览器。Blender 离线渲染与网页画面分别检查，不互相替代。

WebMCP 为可选实验接口，使用 `document.modelContext` 检测，不支持时不会影响地图。此环境没有可用的 WebMCP 验证上下文，未验证浏览器工具注册/调用；不将类型检查或构建通过当作 WebMCP 测试通过。

已提供网页内失败提示、重新载入入口、图形上下文中断提示，以及全屏与导出失败反馈。

最终模型数据复核：6,697 个源建筑要素，水面三角形面积覆盖率 100%，15 个地理定位探索点、14 个独立地标模型、4,670 棵显示树木。Draco GLB 为 2,930,748 字节，比上一版增加 28,628 字节。补充建筑与水面、公园无交叠；新建地标占地范围内，按中心点剔除常规建筑体块，并移除树木，减少重复叠加。
