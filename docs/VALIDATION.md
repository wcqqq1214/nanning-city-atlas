# 验证记录

日期：2026-09-08。环境：macOS Apple Silicon、Node.js 26.8.1、Blender 5.2.1、桌面 Chrome。下列内容为本轮扩区与手机体验更新的验证。

## 构建与数据

- TypeScript 类型检查、Oxlint 与 Git 补丁空白检查。
- GitHub Pages 静态生产构建，检查子目录资源前缀及两种 GLB、目录和 Draco 解码器文件。
- Blender 生成完整可编辑 `.blend`、精细 GLB 和轻量 GLB，并渲染扩展后的全景 PNG。
- 统一范围 108.12–108.48 / 22.70–22.95；原始高程网格 390 × 294，20 张 z12 高程瓦片。
- 10,592 个源建筑要素（6,035 个地图建筑、4,557 个示意建筑），其中 1,551 个位于旧西边界以西。
- 水面三角形面积覆盖率 100%，示意建筑与水面、公园无交叠；21 个点的目录一致性、经纬度与场景投影通过检查。
- 精细模型 7,470,232 字节、1,148,396 个三角形；轻量模型 3,256,212 字节、461,438 个三角形。逐个比较两版建筑、道路、水面和地标的几何数量，确认轻量化只替换地形和植被。
- 14 个独立地标模型；精细树木 10,986 棵，轻量树木 2,747 棵。

## 交互

- 桌面浏览器检查会展中心花瓣、柱廊和台阶，大桥弯曲桥面、斜拱、吊杆与桥墩，文化艺术中心山体与格栅屋面。
- 直接点击三维模型可选择地标，已从大桥近景点击艺术中心模型验证。
- 检查 21 站漫游、自动继续进入城西路线、暂停，以及末站“下一站”回到石埠首站。
- 390 × 844、360 × 780 竖屏与 844 × 390 横屏检查菜单打开、滚动、选点、关闭、焦点恢复与地图操作按钮。
- 手机菜单打开时，可访问性树只暴露菜单；关闭动画完成后菜单退出可访问性树。
- 检查自动/精细画质切换，实际加载相应模型，并保留当前地标和环境设置。检查艺术中心手机近景、说明展开与收起，以及罗文城西观察点。
- 检查流畅模式静止后停止重复绘制、环绕时恢复绘制，以及自动模式在持续低帧率时降低像素比例。诊断读数仅来自本机浏览器，不当作真机性能成绩。
- 从轻量模式导出 PNG 并打开检查，画面有效，未出现空白或黑图。
- 点触识别的 5 项针对性单元测试：手指轻微抖动、双指释放顺序、拖动回原点、取消与次要按钮、DOM 事件原型字段。该测试验证输入序列逻辑，不替代真实双指触屏操作。

## 验证边界

没有连接手机进行实机测试，未测量 iPhone/Android GPU、发热、蜂窝网络冷启动或弱网加载，也未覆盖全部浏览器。尺寸模拟不等于真实触屏、手机性能或 Safari 安全区域验证。当前模型按空间分组剔除视野外对象，但仍一次下载所选 GLB，没有按城区流式下载。

WebMCP 为此前保留的可选实验接口，本轮没有可用的注册/调用验证上下文，不将类型检查或构建通过当作 WebMCP 测试通过。
