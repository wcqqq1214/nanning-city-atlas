# 民族大道模型

模型替换城区数据中民族大道与民族大道辅路的 111 段通用道路：67 段主路、44 段辅路，其中 19 段带有桥梁标记。保留原始 OSM 折线和分合流节点，两条行车方向、辅路合计约 54.78 km；这一数字不是大道单程长度。

## 数据与表现

`data/minzu-source.json` 保存 2026-09-08 城区 OSM 快照中的原始线位、节点、车道数、桥隧标记及相邻连接道路。`data/minzu-plan.json` 记录替换索引、原始曲线采样、路口开口、树木避让和输入哈希。网页仅下载导出的城市模型与轻量元数据。

- 主路与辅路按各自源线位绘制，按 OSM 的 2–5 车道标记分配标线；未记录车道数的辅路按两车道展示。
- 复用清厢快速路已有的沥青、浅色标线、混凝土、阴影面和金属材质，不新增贴图。路缘内侧的窄绿化带复用南湖草地材质。
- 路口和分合流区域断开路缘、绿化带及纵向标线；带 `turn:lanes` 标签的路段绘制对应转向箭头。
- 道路贴合两档展示地形，桥段具备桥面厚度和端部桥台。共享源节点采用同一高程，进出桥段控制展示坡度，相邻保留道路在连接处平滑抬升。
- 两段 OSM 下穿隧道保留在计划中，地表模型继续留空，避免用路面盖住上层道路；不把无法从俯视看到的隧道内部作为额外下载细节。
- 车道宽度、路缘尺度、灯具、绿化与桥台采用沙盘展示假设，不是道路实测或工程设计。原始线路数据与实际车道数标签保持独立。

## 体积控制

结构使用曲线与高程自适应分段：最大跨度 60 m、误差 0.4 m，原始源节点作为保留点。细节按空间合批；精细档提供车道线、转向箭头和约 90 m 间隔的路灯，流畅档保留主体及标线、省略灯具与箭头。标线采用单面几何，不逐块制作铺装或加载纹理。民族大道网格使用 18 位 Draco 位置量化，避免窄标线被压缩吞掉。

## 重建与验证

```sh
# 首次从已保留的城区快照捕获，或明确刷新来源时使用：
work/venv/bin/python scripts/prepare_minzu.py --capture
# 日常重建复用版本化来源：
work/venv/bin/python scripts/prepare_minzu.py
npm run models:build
work/venv/bin/python scripts/validate_minzu.py
work/venv/bin/python scripts/validate_assets.py
npm run build:pages
```

模型位于 `Roads > MinzuAvenue`，随“道路桥梁”图层开关。完整可编辑场景仍保存为 `blender/nanning-city.blend`；修改前备份保存在本地 `work/minzu-avenue/before.blend`。

验证覆盖原始道路完整性、旧道路替换、桥隧标签、构建时两档地形净空与坡度、图层归属、清厢材质复用以及 Draco 解码后的路面覆盖和窄标线退化率。

当前完整城市模型为精细档 13,407,920 字节 / 1,848,723 三角面，流畅档 9,979,284 字节 / 1,354,439 三角面。相较铁路优化后的版本分别增加约 0.320 MB 和 0.256 MB。民族大道主体为 20,368 三角面，细节为 22,033 / 9,316 三角面；精细档包含 284 根路灯和 19 个依据源标签绘制的转向箭头。

本轮 `scripts/validate_assets.py` 全量检查与 `npm run build:pages` 通过。构建检查的最小地形净空为 5.965 展示米；解码后精细档 11,809 个标线三角面、流畅档 9,316 个标线三角面均无退化，道路源点距实际路面的最大平面误差约 0.007 m。该数值仅描述几何导出误差，不代表源数据测绘精度。

发布构建的浏览器检查覆盖广西博物馆附近的老城段、华润大厦附近的凤岭段以及俯视布局，两档画质均可加载，未发现控制台错误。
