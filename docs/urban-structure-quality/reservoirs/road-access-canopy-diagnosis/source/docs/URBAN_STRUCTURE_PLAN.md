# 城市结构与场地衔接优化计划

创建：2026-09-12。起始版本：`73edbb7`。目标：有真实城市结构的风格化南宁沙盘，优先改善街区组织、建筑落地、滨水断面、山体衔接和地标比例。按 P0–P5 逐步实施，保留每阶段的验证证据。

## 执行路线与批次门槛

总体顺序：**统一对照基线 → 住宅街区样板 → 连续滨水样板 → 青秀山局部地形 → 代表性地标校准 → 分区推广与整城验收**。暂不引入游戏化。每个样板先证明布局和空间关系成立，再增加中等尺度结构与材质表现。

| 阶段 | 首要成果 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 | 可恢复的固定镜头、灰模/基础色/光照对照、比例样本 | 同条件截图可复现，来源尺寸与显示夸张可区分 |
| P1 | 一个来源明确、楼群有组织的住宅街区 | 保留已知 OSM 足印，组团与庭院成立，范围外无意外变化 |
| P2 | 一段贯通水面、岸坡或岸墙、步道、绿带和桥头的滨水界面 | 接缝与支承通过，两档近景均无明显裂缝和悬空 |
| P3 | 按山体、湖岸、平台与园路分别约束的局部地形 | 局部网格正确替换原面，依附物采样最终地面 |
| P4 | 代表性地标的大形、比例、屋顶和落地关系 | 尺寸来源与估计分开记录，灰模和日间对照成立 |
| P5 | 四类用途模板、足印/高度质量改善及完整城市资产 | 道路、场地、建筑和植被依赖一致，预算、视觉与交互验收完成 |

每批先冻结输入、替换范围与对照视角，再准备候选；独立检查通过后接入组合场景，最后更新正式资产。候选的平均指标改善但局部缺陷加重时，应保留原方案并记录取舍，不能仅凭平均值接受。

P5 的收尾顺序为：确定最终地形与岸线 → 基础建筑支承 → 道路准备与实体求解 → 场地接路与最终地形 → 最终建筑支承及植被 → 两档完整导出 → 同条件网页与预算验收。下游结果必须绑定当前输入，避免把旧候选文件直接当作新组合的验证证据。

## 已有基础与约束

- 使用现有 Copernicus GLO-30 源数据、约 60 m 显示网格、城区去突起、商场平台与道路重建。保留原始 `heights`、来源、全城地势和水域边界。细分属于显示改善。
- 复用南湖替换地形补片、两档边界对齐、道路支承与既有桥梁接口。新局部网格替换原面，不能叠盖粗网格。
- 起始数据为 6,035 个 OSM 建筑与 13,882 栋示意补楼。首个样板保留 OSM 建筑形状与高度，试点外形状、高度、材质和植被保持一致。
- 场景每单位 100 m。Blender X 东、Y 北、Z 上；Three.js X 东、Y 上、Z 南。普通建筑生成高度放大 1.55 倍，地形高差放大 1.35 倍；网页高度 1.0× 不等于中性比例。
- 铁路建筑避让、道路限高当前按建筑数组索引关联；改变数组后要重算关联。地理、地形、道路、林冠的输入哈希必须一致，不能只执行 prepare 后直接复用旧道路导出。
- 起始精细 GLB：25,236,380 字节 / 3,462,527 三角面；流畅 GLB：17,270,232 字节 / 2,350,419 三角面。现有文件预算分别为 26,000,000 / 18,000,000 字节。默认保持现有预算及分项几何约束，记录每次净增减。

## P0：视觉与比例基线

1. 保存全景、住宅街区、滨水、青秀山、艺术中心、镇宁炮台的固定相机位置、目标点、FOV、画布尺寸、像素比、光照、图层、画质和资源版本。
2. 增加独立检查入口，提供灰模、基础颜色、完整光照，固定水面动画时间，暂停环绕和漫游；支持导出参数及可恢复镜头链接。
3. 保存同机位两档画质的基线截图。近景增加俯视或低斜视，主验收先看日间，之后复核日落与夜间。
4. 单独生成有来源约束的中性比例样本，比较生成参数中的地形、建筑及地标独立放大。不能用全城 Y 轴滑块替代比例校准。
5. 汇总资源哈希、实际 GLB 面数与字节、相机和观察结论，建立本计划后续各阶段的共同参照。

验收：固定链接可恢复镜头和检查设置；普通浏览模式不受检查工具影响；灰模与基础颜色确实使用对应材质；同条件重复截图无动画漂移；参数记录可区分源数据、模型放大和网页高度倍率。完成截图与比例样本后才将 P0 标为完成。

## P1：住宅街区样板

初选香榭里花园，OSM way `766539182`，约 8.32 公顷，范围约 108.37944–108.38238 / 22.81760–22.82055。本地快照有住宅公寓用地标记，现有边界内相交统计为 18 栋程序楼、0 栋 OSM 建筑。具体楼型、布局、栋数、高度仍需公开资料核实。备选南湖公务员小区，不同时建设两个样板。

来源核对、OSM 原始边界、模板估计参数及基线替换索引保存在 [香榭里样板来源](../data/block-sources/xiangxieli.json)。样板采用 13 栋按组团排列的板楼，不能据此宣称住宅内部布局已完成实景复原。

1. 保存地块来源、轮廓、用途、照片/总平面证据与估计项；恢复稳定的地块和建筑标识，分别记录 height、levels 与 estimate 高度来源。
2. 按“地块与用途 → 组团朝向/庭院 → 楼栋足印 → 关联高度 → 屋顶与材质”实现首个有依据的住宅类型。
3. 试点使用地块/楼栋独立随机种子；试点外沿用已验证输出，避免改变一个地块扰动全城后续随机序列。
4. 同步扩展 `blender/build_city.py` 的建筑体块消费端；需要庭院时保留内洞，不能被外环屋顶填死。检查楼脚与场地多点高差。
5. 重新生成受影响的铁路、道路限高、道路实体、林冠计划，产出完整 `.blend` 和两档 GLB。

验收：样板朝向、间距、占地、高度范围符合有来源的规则；水域、公园、道路、OSM 建筑与补楼避让通过；庭院开敞、体块和来源计划一致；同输入重复生成稳定；试点外几何与配色保持一致；两档布局一致；记录资源增量与同条件视觉/性能结果。

## P2：连续滨水样板

初选畅游阁—邕江大桥北岸，按实际岸线与道路切出约 500–800 m，最终边界由基线与资料确定。备选亭子码头—凌铁大桥邻近岸段。

1. 记录岸线、岸顶/岸脚、步道、绿带、桥头端口、场地及其来源/估计状态。
2. 先实现一种城市硬质护岸与桥头过渡，构成“水 → 岸墙/岸坡 → 步道 → 绿带 → 城市道路”。
3. 提炼南湖已有局部补片入口，统一最终地形采样；竖直护岸单独生成墙面，缓坡通过替换地形表达。
4. 复用已有桥梁结构和道路端口，衔接桥台、引道、堤岸；几何成立后再增加少量材质和植被层次。

验收：俯视、对岸斜视和桥头近景成立；替换区只覆盖一次；步道不盖水；补片接缝高程吻合；两档均无明显悬空、裂缝或穿插；重新验证受影响道路、桥梁、林冠与资源。

## P3：青秀山局部地形

1. 初选龙象塔附近能覆盖山脊、园路、山脚城市界面的局部区域，保存范围和剖面。
2. 保留山脊、谷地和坡向；区分山体、建筑平台、城市道路和园路约束。园路采样最终山体，不沿路整体压平。
3. 在地形变化线、平台和道路边缘加细；精细/流畅面与道路、树木、林冠共用对应的最终表面。
4. 按 [地形重采样流程](TERRAIN_RESAMPLING.md) 更新依赖，再生成两档模型。

验收：原始高程和全城基准不变；山脊与剖面有依据；园路贴地、平台落地、边缘连续；两档地形和依附物一致；局部增量与预算记录完整。

## P4：地标校准

已选择艺术中心、镇宁炮台和地王大厦，见[当前候选及验证](URBAN_STRUCTURE_LANDMARKS.md)。另按实际足印和场地关系复核 P3 记录的孔庙旧台基与局部高地衔接问题。

1. 记录真实/有来源的足印、中心、朝向、长宽比、高度、基座，明确照片估计、展示倍率与不确定项。
2. 先通过大形灰模，再调整裙房、屋顶、入口、院落和台阶，最后处理可见表面细节。
3. 检查独立放大与周边关系，依据对照决定显示参数；同步更新替换边界、平台、镜头、标记高度及依赖。

验收：每处均有参数来源、比例对照、正侧背/俯视检查；落地且与周边体量协调；选中、定位、图层和两档切换正确；不把缺少资料的估计当作实测。

## P5：分区推广与数据质量

当前进度见[候选实现与剩余范围](URBAN_STRUCTURE_QUALITY.md)。已完成 OSM 建筑候选和数据层验证；正式导出、分区推广与场景验收尚未完成。

P4 重建期间的只读盘点发现：6,035 个 OSM 建筑记录中，73 个标记为直接高度、483 个标记为楼层推算、5,479 个仍采用默认估计。1,348 个原始多边形在旧 3.5 m 简化前后的对称差面积超过原面积的 4%；这是候选筛选指标，并非逐栋视觉缺陷结论。P5 应先复核小型复杂足印及有用途依据的未知高度，再按批次替换。盘点保存在 `work/urban-structure/p5/inventory.json`，尚未修改这些建筑。

最初盘点的 97 个映射建筑记录包含内洞，但旧普通建筑消费端只读取外环。现已增加内洞消费端，独立原生和压缩检查保留 125 个开口；实际场地支承与正式城市资产接入仍待完成，不能将独立几何检查等同于完整验收。

1. 把已通过样板的组团、护岸和地形规则按小批次推广，记录范围、替换清单、来源和前后对照。
2. 增加有依据的其他住宅、商业、校园、工业模板；校园与工业分别处理。
3. 单独改善 OSM 轮廓简化：按尺寸/重要程度设容差，保留窄翼、院落和转角。
4. 单独改善未知高度：根据用途和有来源的邻近建筑保守估计，输出方法与来源标记；保留已知高度。
5. 以区域覆盖、组团结构、空间正确性和视觉收益验收，避免把追求补楼数量当作目标。

验收：每批都有明确收益、范围外回归和两档记录；最终覆盖清单与未有资料区域明确；性能与资源未越过既定预算；文档、生成器和公开资产一致。
