# 会展中心重建记录

已把原来的漏空伞骨轮廓改为连续的十二瓣内收花冠，并细化圆形玻璃大厅、水平檐口、窗框、双侧入口台阶和后方双层展厅。屋面保留折线，面内采用平滑法线；顶部收口内凹，避免穿出花瓣。

## 参考与精度

参考 [gmp 项目实景、平面与剖面](https://www.gmp.de/en/projects/403/nanning-international-convention-and-exhibition-center-china) 校准建筑特征。照片署名 Jan Siefke。仅使用自建网格和材质，参考照片没有打包进模型。

这仍是与城市沙盘一致的简化模型：建筑尺寸经过展示放大，附属展厅与场地采用近似体量，未依据测绘或施工模型复原。

## 集成

以下大小记录会展中心重建时的模型；当前全城模型统计见 [手机体验](MOBILE.md)。

- 模型入口：`blender/expo_landmark.py`；全场景生成入口：`blender/build_city.py`。
- 桌面 GLB：7,661,316 字节，1,170,704 三角形。
- 轻量 GLB：3,447,116 字节，483,883 三角形。会展中心几何与桌面一致。
- `blender/nanning-city.blend` 保存可编辑的完整城市。
- 会展中心范围内的展示地形做平缓衔接，避免粗地形穿过门厅；原始高程数据保持原样。

## 验证

Blender 重建、GLB 资产校验和静态站点构建通过；Safari 已验证精细与流畅模式下的会展中心近景和环绕。公共站点随 `main` 分支的 GitHub Pages 工作流发布；已有录制视频需另行重录才能包含新模型。
