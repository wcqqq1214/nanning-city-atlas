# 全图地面道路

本轮替换现有地理数据库中的 9,039 段普通地面道路，沿用地图现有线位。民族大道、清厢快速路以及桥梁任务的精细模型保留独立生成逻辑；不把高架或桥段摊平到地面，也不新增高架结构。当前数据库中 1,202 段带桥梁标记的道路不属于本轮地面替换范围。

## 路面表现

- 主路复用清厢快速路的鼠尾草灰沥青和浅色标线。只使用约 13,351 段克制的中央虚线，路口与分合流处留白，不逐车道铺设复杂构件。
- 次干路使用稍浅的灰绿路面；小路采用更淡的单色铺装，无灯具、路缘石阵列和附加贴图。
- 展示宽度按主路 16 m、次干路 10.5 m、支路 7 m、小路 5 m 分级，属于沙盘表达，不代表道路实测宽度或车道数。
- 同级相交路面先合并，再按道路级别裁分材质。十字路口、丁字口和并行近接路段不再叠放多张共面矩形。

## 穿模与衔接

路面轮廓扣除水域、建筑脚印以及既有精细地标占地，并保留少量边缘余量。使用实际树冠半径做避让，林冠覆盖仍沿用现有更宽的道路清除通道。

两档路面各自依照该档实际地形三角面切分，包含南湖的替换地形和流畅档镇宁炮台的细分补丁。南湖补丁边界的道路局部取两侧较高边缘剖面并过渡，避免精细补丁与粗地形之间的高度差影响路面。普通路面高出支撑地形 0.8 展示米；同一支撑三角面内的路面与地形均为线性平面，因此可以检查完整重叠区域，而不是只检查道路中心点。

民族大道及清厢快速路的地面边界从原有已验证 GLB 捕获，连接处平滑过渡到已有路面高程。原有普通桥头仅在高程相近时保留端口约束；旧高架高于地面超过 35 展示米的端口不向地面传播抬升，留待高架专项调整。新增主要桥梁则在构建时读取实际桥头位置和高度。抬高的接坡侧边补齐挡面，避免出现悬空薄片。

标线按实际路面三角面再次裁剪，并通过其支撑面的重心坐标求高程，高出路面 0.20 展示米，留出压缩后跨相邻三角面边缘的净空。异常陡峭的接坡碎片不绘制窄标线。导出时地面道路及地形使用 18 位 Draco 位置量化，降低窄标线丢失和路面被量化到地形下方的风险。

## 数据与重建

`data/ground-roads-context.json` 保存原有精细地标脚印、道路边界与桥头端口的快照及来源模型哈希。地面网格计划使用确定性 gzip 保存为 `data/ground-roads-plan.json.gz`，减少仓库存储；网页不会下载这两个离线建模文件。

```sh
# 首次捕获，或相关精细地标/道路模型已改变后，先重建这些模型再捕获：
work/venv/bin/python scripts/prepare_ground_roads.py --capture
# 相同精细边界下重建，复用版本化快照：
work/venv/bin/python scripts/prepare_ground_roads.py
npm run models:build
work/venv/bin/python scripts/validate_ground_roads.py
work/venv/bin/python scripts/validate_assets.py
npm run build:pages
```

计划哈希针对解压后的确定性 JSON 内容计算，与 gzip 文件头无关。模型保存于 `Roads > GroundRoads`，随“道路桥梁”开关。两档各自有贴合地形的路面，主体路径和材质分区相同；原始可编辑场景与本轮修改前备份分别保留在 `blender/nanning-city.blend` 和本地 `work/ground-roads/before.blend`。

验证脚本核对道路替换范围、材质区域不重叠、水域/建筑/树冠避让，以及解码后道路与实际地形、标线与实际道路的完整平面重叠区域净空。

## 本轮导出规模

覆盖 37.582 km² 的地面铺装，移除 732 棵实际可见、树冠侵入路面的程序树。离线计划不会增加页面请求。

| 项目 | 精细档 | 流畅档 |
| --- | ---: | ---: |
| 整城 GLB 字节数 | 16,216,612 | 11,694,376 |
| 整城三角面 | 2,269,589 | 1,593,270 |
| 新地面路面三角面 | 277,110 | 182,668 |
| 接坡侧面三角面 | 23,670 | 17,908 |
| 标线计划输出三角面 | 44,016 | 37,122 |

整城数字包含同期桥梁任务新增的 12 座主要桥梁，不应全部计为地面道路增量。极细标线经 Draco 导出可能少 1 个退化三角面，验证按实际解码网格进行。

生产页面构建 `npm run build:pages` 通过。浏览器检查了南湖两档画质、校园周边最终画面及道路图层开关；错误日志为空。

实际 Draco 解码后三角面完整 XY 重叠区域的最小净空如下（均为沙盘展示米）：

| 净空 | 精细档 | 流畅档 |
| --- | ---: | ---: |
| 地面道路 / 地形 | 0.6413 m | 0.6684 m |
| 标线 / 地面道路 | 0.1211 m | 0.0591 m |

不同材质分别压缩时，共用边缘会有厘米级位置差异。覆盖检查同时限制缺口宽度不超过 6 cm、累计面积低于路面面积的 0.01%，避免把细边缘量化误差误判为缺失整段道路。路面和标线穿入支撑面的检查不放宽，均要求净空大于零。

最终 `work/venv/bin/python -u scripts/validate_assets.py` 全量检查通过，包括两档道路覆盖、净空、建筑/水域/树冠避让，以及既有铁路、民族大道、清厢快速路和主要桥梁检查。
