# 邕城：风格与菜单设计

## 场景定位

一个可以直接操作的南宁城市地理沙盘。进入页面就能观察三维城市，左侧为目录和配置，右侧地图始终是工作主体。重点表现邕江河谷、青秀山、南湖及城区街坊的空间关系。

## 视觉规范

| 对象 | 处理 |
| --- | --- |
| 地形 | 真实 DEM 采样，低面数三角网，保留盆地与低山丘陵起伏；地形边缘显示切片底座 |
| 河湖 | OSM 水面多边形，保留内环与岛屿；青绿色流动细波纹 |
| 建筑 | 浅色挤出体块，冷暖轻微区分，统一屋顶色；玻璃地标使用深青绿色 |
| 植被 | 低面数宽叶树冠，三档绿色，沿公园与滨水绿带分布 |
| 地标 | 龙象塔层叠檐口、会展中心放射花瓣、艺术中心三座山体与云棚、民族博物馆铜鼓轮廓、镇宁炮台环形堡垒、汇学堂坡屋顶与柱廊、东站连续屋盖 |
| 细节色 | 黄铜 `#d3ae6b`、朱红 `#b9654c`；用于屋顶与桥梁 |
| 界面 | 近白色侧栏、墨绿色文字、细线分隔，地图上叠加少量半透明控制 |
| 动效 | 1.5 秒缓动镜头，6.5 秒一站的漫游，轻微水纹；尊重减少动态效果偏好 |

页面以系统中文无衬线字体为主体，品牌名称使用中文衬线。常用控制和说明维持清楚可读的字号，说明抽屉使用更宽松的段落排版。

## 菜单与功能说明

### 探索

“邕江两岸”复位到中心城区鸟瞰。15 个探索点有名称、分类、编号；点击后更新选择状态、镜头、地图标记和地标详情。详情卡提供位置、空间描述及下一站入口。14 个独立地标模型与地图标记可点击；南湖由湖泊标记进入。镜头距离按场地尺度配置，并适应窄屏。地标目录统一维护在 `data/landmarks.json`。

### 图层

- 城市建筑：常规街区体块与建筑地标。
- 林木植被：公园与河岸树木，关闭后仍保留地形自身的绿色。
- 道路桥梁：道路、桥面与跨江连接。
- 河流湖泊：水面层；关闭后可看到为表现河床而调整的地形底部。
- 地名标注：HTML 标注层，按实际标签宽度避让相邻标记，选中点优先显示，避免长名称挤在一起。

“全部显示”恢复五个图层。下方数据卡区分 OSM 建筑和程序化补充建筑。

### 环境

时间滑杆覆盖 06:00–22:00，每次半小时；四个按钮快速切换晨光、日间、日落和夜色。它改变天空背景、光源方向与颜色、环境光、水面颜色和地标弱发光，不代表实时日照。

高度夸张滑杆覆盖 0.5–2.0 倍，作用于整个已艺术化处理的模型。俯视模式飞到近垂直角度，环绕观察围绕当前镜头中心缓慢旋转。“恢复默认环境”恢复 14:00、1.0 倍、倾斜、停止环绕。

### 城市漫游

依次访问老城、人民公园、广西大学、广西博物馆、南湖、商务区、南宁东站，再沿民族博物馆、孔庙、青秀山、南宁大桥、文化艺术中心和亭子码头回到邕江沿线，共 15 站。可暂停和继续；拖动地图或手动选点会暂停自动漫游。系统开启减少动态效果时仍可漫游，但镜头立即定位，不播放飞行动画。

### 地图控制

指北针将镜头方位对准正北；加减按钮缩放；定位框复位全景；图层形状按钮切换俯视；全屏按钮使用浏览器全屏接口。小地图保留真实河湖轮廓、地标点和当前选择，点击返回全景。

### 导出与说明

导出按钮保存当前 WebGL 画面，不含菜单和 HTML 标签。项目说明抽屉列出操作方式、地理范围、夸张比例、数据来源及限制。

## 小屏与可访问性

手机上将侧栏收为“城市菜单”，画布保留一指旋转与双指缩放/平移。图层开关、环境滑杆、导航选项使用语义化控件。地图可通过键盘平移、缩放和复位；图标按钮提供可读名称，重要动作有可见反馈。

## 不属于本版的功能

不提供实时交通、天气、测绘量测、实景纹理、逐栋建筑信息或行政区边界查询。后续若接入更精细数据，应保留当前坐标约定和来源说明，替换对应具名图层。
