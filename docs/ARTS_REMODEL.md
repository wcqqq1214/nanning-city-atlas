# 广西文化艺术中心重建

2026-09-09：将原先一字排列的低面数山体和矩形栅板，替换为三角布局的歌剧院、音乐厅、多功能厅，以及随场馆曲面连续起伏的白色格栅屋盖。

## 造型与来源

- [gmp 项目实景、总平面与剖面](https://www.gmp.de/en/projects/3231/guangxi-culture-arts-center)用于核对三座场馆的相对位置、曲面外壳、连体屋盖、斜向立面构件和门厅。摄影 Christian Gahl；照片和图纸仅作参考，未打包进模型或网站。
- 屋盖边界取自既有 OSM 快照中的 [way 819620330](https://www.openstreetmap.org/way/819620330)，以闭合曲线平滑。三个场馆的曲面、格栅和附属细节为自建近似几何，不是施工模型。
- 约 60 条平行格栅使用有厚度的几何，穿过三座上部曲面。曲面采用平滑法线，格栅侧面保留板材边缘；外壳后方设置灰绿色玻璃门厅、细窗框和入口门扇。
- 公共石质基座随三叶形边界展开，并设置连续台阶和局部扶手。基座保持水平，基础底边跟随显示地形，避免悬空；不改变原始地形和水面数据。
- 屋盖平面相对于地图轮廓放大约 1.2 倍，主体高度保持自建的近似比例。收回旧版过大的矩形平台，以避免侵入地图水面。近景距离和标记高度随新体量调整。

## 文件与验证

生成入口为 `blender/arts_landmark.py`，由 `blender/build_city.py` 集成。完整可编辑城市保存在 `blender/nanning-city.blend`；精细和流畅 GLB 使用同一份艺术中心几何。

`scripts/validate_assets.py` 检查公共基座与真实地图水面、替换边界的关系，并比较两种模型的建筑与地标几何数量。当前全城模型大小见 [手机体验](MOBILE.md)，本轮验证见 [验证记录](VALIDATION.md)。

网页中的定位圆环恢复正常深度遮挡，不再透过屋盖绘制。地名标记和探索列表继续显示选择状态。
