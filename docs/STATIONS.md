# 南宁站与南宁东站精细建模

两座车站使用独立的 `Landmark_nanning-station`、`Landmark_east-station` 网格，精细和流畅画质共享完整几何。南宁站新增到老城段的探索菜单、地图标记和自动漫游；南宁东站替换原先的六段波浪屋盖模型。

## 南宁站

保留既有站房的中央大钟、红色“南宁站”字样、横向玻璃幕墙、双弧屋顶和中央入口。增加窗框、钟面刻度和指针、入口柱、台阶、前庭蓝色雨棚，以及后方七座站台的雨棚、支柱、安全线和轨道。钟面为固定示意时间。

站房位置与朝向来自 [OSM way 286249877](https://www.openstreetmap.org/way/286249877)，入口朝向东南，横向轴线相对正东约 29.38°。外观参照 [中国铁路 12306 南宁站资料](https://www.12306.cn/mormhweb/czyd_2143/gx/nn/201808/t20180823_390842.html)中的正面照片，以及 [南宁晚报 2018 年现状照片](https://v.gxnews.com.cn/a/17822196)。没有采用报道中的历史站房照片或未来改建方案。

## 南宁东站

重做由两翼向中央抬升的三层银白屋檐、屋面分缝、层间采光带、南北门式入口、每侧十二根分叉柱、玻璃幕墙和檐下斜交构架。增加高架候车厅、落客平台、台阶及两侧十三座站台的雨棚与轨道。

主体轮廓来自 [OSM relation 11968494](https://www.openstreetmap.org/relation/11968494)。站房长轴沿南北方向跨越东西向轨道，修正旧模型中东西向长站房的朝向。位置使用站房最小旋转矩形中心，替换此前的站区集合关系中心。

建筑特征参考设计单位的[南宁东站项目介绍](https://design.citic/portal/article/project_detail/id/642/cid/35.html)、[国家铁路局工程资料](https://www.nra.gov.cn/ztzl/hd/cxdh/cxcg/lbj/201706/t20170630_146854.shtml)及[国际在线站房与南广场实景](https://gx.cri.cn/n/20210106/c8bc2d18-f0b1-a803-ac10-7ad7f414b0a2.html)。三层屋盖和分叉柱廊为建成外观的沙盘重建。

## 地理与重建

`data/stations-source.json` 保留公开 Overpass 查询、来源和 `2026-09-09T16:44:27Z` 的 OSM 快照，属于 © OpenStreetMap contributors / ODbL 数据。`scripts/prepare_stations.py` 将站房轮廓、七座和十三座站台、站区内轨道片段投影到本地坐标，生成 `data/stations-plan.json`。地下地铁站台被排除；轨道按原始线段裁剪，不把线段数量当成股道数量。

水平坐标保持地图比例，每单位约 100 m；建筑高度沿用全城 1.55 倍的展示比例。站房屋顶剖面、幕墙分格、支柱、雨棚高度和小构件按照片近似，并非施工图复刻。红色站名使用自绘笔画几何，无新增字体、纹理或运行时网络请求。

两站使用与站场方向一致的替换边界，避开重复的普通建筑、树木与林冠。低分辨率 DEM 无法分辨站场整平，显示地形在站场及外围采样余量内整平，随后平滑过渡；地面道路和建筑共用修正，原始高程数据保持原值。两档地形都检查站台基础下方的地面高度。

```bash
python3 scripts/prepare_stations.py
python3 scripts/prepare_forest_canopy.py --stage all
npm run models:build
python3 scripts/validate_assets.py
```

车站位置、模型文件及验证结果随同目录一起生成；菜单图标、默认镜头和近景镜头分别按两座车站的尺寸设置。

相对城市林地优化完成时，精细 GLB 增加 208,864 字节、42,802 面；流畅 GLB 增加 213,260 字节、42,822 面。两座车站在两档中完全一致，净增面数还包含旧东站模型替换、站场内普通建筑与树木的避让。轨枕只保留可见顶面，屋面分缝减少无必要分段。

类型检查、lint、5 项点触测试、Python 编译、地理与 GLB 验证、GitHub Pages 静态构建通过。检查了两站的精细/流畅近景、地标切换和东站 205° 默认镜头；浏览器无警告或错误，静态构建中的模型和地标目录与源资产一致。本次未进行手机真机性能测试。
