# 亭子码头与南宁大桥重建

日期：2026-09-09。两处均替换旧模型，探索目录仍为 21 站。

## 亭子码头

旧模型使用层叠中式屋檐，与现有滨水街区外观不符。新模型包含三座红色尖塔、白色外墙与线脚、逐层拱窗、三层平顶长廊、两层红顶商铺，以及蓝灰色圆顶柱廊。尖塔上使用实景中的拱窗，没有添加钟面。

街区沿约 42.1° 的东北方向展开，参照缓存的 OSM 商业建筑轮廓；独立游船码头采用 OSM way 1423783210 的带缺口平面。石质基座底边随显示地形落地。替换范围缩小为沿街区旋转的区域，保留西北侧广西民族剧院；建筑基座未与地图水面相交。标签锚点移到三座尖塔的中塔位置，近景从西南侧沿步行街取景；树木排除范围考虑树冠半径。

参考：[中新网广西，陈冠言摄，2023-05-28](https://www.gx.chinanews.com.cn/sh/2023-05-28/detail-ihcpswxf4323137.shtml)。参考照片仅用于观察，没有作为项目纹理或网页素材发布。

## 南宁大桥

用地图中两条方向相反的车道线计算共同中心线，再平滑连接控制点。替换旧的两条道路贴片，桥面增加钢箱底部、六车道标线、人行边带、栏杆、路灯、伸缩缝和引桥桥墩。两端随地形平缓接回道路。

主跨取约 300.5 米，两条朱红色钢箱拱肋分别位于独立的外倾平面，通过斜吊杆连接曲线桥面；没有添加拱肋之间的横撑。采用连续倒角截面、斜向混凝土拱脚与吊杆锚座。主跨内不添加桥墩。地图锚点移到实际生成的主跨中点。

参考：[OPAC 设计说明及平立剖图](https://www.opacengineers.com/features/Nanning)、[OPAC 项目照片](https://www.opacengineers.com/projects/Nanning)、[中国中铁建成项目资料](https://www.crecg.com/crecien/projects/infrastructure_construction/bridges/2023091915545660842/index.html)。横断面参考图中的两侧倾角约为相对竖直 19.4° 与 24.4°，用于表达不同的拱肋平面；不把早期设计尺寸当作实桥测绘结果。
